# Digital Hive Portfolio

## Purpose

This project is my personal software engineering portfolio.

The goal is to create a memorable portfolio that showcases my projects, skills, experience, and technical abilities.

The website should feel handcrafted rather than AI-generated.

---

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- App Router
- Framer Motion
- shadcn/ui
- Lucide React

---

## Coding Principles

- Production-ready code
- Clean architecture
- Reusable components
- Responsive
- Accessible
- High performance
- Maintainable

---

## Rules

Do NOT generate generic AI portfolio layouts.

Avoid:

- Generic hero sections
- Floating blobs
- Dashboard-looking UI
- Excessive gradients
- Huge glassmorphism panels
- Generic cards
- Heavy cyberpunk aesthetics

Whenever possible:

- Prefer elegant simplicity.
- Prioritize UX over flashy visuals.
- Keep animations subtle.
- Explain architectural decisions before coding.
